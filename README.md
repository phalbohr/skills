# Skills, die ich verwende

## Skills in diesem Repository

Die Skills außer **ast-grep**, **graphify** und **postman** sind von mir geschrieben. Die drei werden von meinen **code-search** bzw. **review-with-postman** Skills benutzt.

- **code-search** — Routing-Leitfaden zwischen ast-grep, graphify und direktem Lesen für Codesuche.
  - **ast-grep** — Regeln für strukturelle Codesuche mit AST-Mustern statt reinem Text.
  - **graphify** — Baut einen Wissensgraphen aus Code/Dokumenten für Architektur- und Abhängigkeitsfragen.
- **clean-code** — Prinzipien aus "Clean Code" (Uncle Bob) für lesbaren, wartbaren Code.
- **code-1-guide** — Java/Spring-Boot-Konventionen für Produktionscode.
- **code-2-test** — Konventionen für das Schreiben von Tests (JUnit, Mockito, AAA-Muster).
- **code-3-optimize** — Analysiert einen PR/MR/Branch-Diff und listet Optimierungspotenziale (HIGH/MEDIUM/LOW).
- **code-4-document** — Fügt Dokumentation (OpenAPI, JavaDoc) gemäß Projektregeln in Produktionscode ein.
- **code-5-style** — Wendet Style-Regeln auf Dateien in einem PR/MR/Branch an.
- **code-6-approve-or-block** — Bewertet einen PR/MR mit Freigabe-/Blockier-Entscheidung.
- **deep-review** — Tiefgehende Code-Reviews nach 13 spezialisierten Prüfpunkten.
- **issue-writer** — Erstellt GitLab-Issues aus Kontext, strukturiert nach Layern.
- **post-mortum** — Schreibt einen Post-Mortem-Bericht über Probleme und Fehler einer Sitzung.
- **review-with-postman** — Reviewt einen MR und erstellt passende Postman-Requests zum verlinkten Issue.
  - **postman** — Verwaltet den API-Lebenszyklus über Postman (Collections, Tests, Mocks, Security-Audits).
- **task-journal** — Schreibt einen ausführlichen Lernbericht über eine abgeschlossene Aufgabe.
- **user-story** — Wandelt Rohtext in eine User Story mit INVEST-Kriterien und Gherkin-Akzeptanzkriterien um.

## Skills von anderen Autoren, die ich häufig verwende.

- **grill-me** — Startet ein intensives Interview, um einen Plan oder ein Design zu schärfen.
- **grill-with-docs** — Wie grill-me, erzeugt zusätzlich ADRs und ein Glossar.
- **grilling** — Stellt dem Nutzer beharrlich Fragen, um eine Idee gegenzuprüfen.
- **handoff** — Fasst die aktuelle Konversation für die Übergabe an einen anderen Agenten zusammen.
- **mermaid-diagrams** — Leitfaden zur Erstellung von Diagrammen (Klassen, Sequenz, ER, C4 usw.) mit Mermaid.
- **pdf-to-markdown** — Konvertiert PDF-Dateien in Markdown, auch mit OCR für gescannte Dokumente.
- **markdown-formatter** — Formatiert Markdown-Dateien nach gängigen Stilrichtlinien.
- **prototype** — Baut einen Wegwerf-Prototyp, um eine konkrete Design- oder Logikfrage zu klären.
- **teach** — Vermittelt dem Nutzer ein neues Konzept über mehrere Sitzungen hinweg.
- **wait-what** — Wiederholt die letzte Erklärung verständlicher, in einfacher Sprache.
- **wayfinder** — Plant große Vorhaben als Entscheidungs-Tickets im Issue-Tracker und arbeitet sie schrittweise ab.
- **writing-for-agents** — Referenz zum Schreiben von Dokumenten für Agenten (Skills, AGENTS.md, CLAUDE.md).

## Installation weiterer Skills

Viele dieser Skills lassen sich auch aus folgendem Repository installieren:

```
npx skills add https://github.com/mattpocock/skills --skill setup-matt-pocock-skills
```
